# Stage7 v2 — Stage6 수식을 유지한 기하 후보 검사

2026-11-04 연구자 결정: Stage6의 중점 원 수식을 유지하고 Stage7을 이에 맞춘다. 가림 중심은 손목 P0와 중지 MCP P9의 중점, 반경은 `dist_xy(P0,P9) * w3_new / 2`다. Stage6 파일·출력 수식은 변경하지 않았다.

이 수식에서 w3>1이면 손목은 원 안에 들어간다. 따라서 기존 “손목을 포함한 손바닥 5지점 모두 원 밖” 조건을 폐기한다. 새 정책 식별자는 `midpoint_middle_pip_visible_fingertips_v2`이며 과거 결과와 구별해 기록한다.

1. **중지 관절 가림:** 기존과 동일하게 중지 PIP P10 및 P9–P10/P10–P11 중간점 3개가 `radius * (1 - condition1_margin_frac)` 안에 있어야 한다. 기본 안쪽 여유는 0.15다.
2. **남는 손 단서:** 엄지·검지·약지·소지 끝점 중 설정한 개수 이상이 `radius * (1 + condition2_margin_frac)` 이상 떨어져 있어야 한다. 중지 끝점은 세지 않는다. 기본 바깥 여유 0.10과 기본 최소 2개는 명시적인 공학 초기값이다. `condition2_min_visible_fingers`는 1~4 범위에서 설정할 수 있다.
3. **전체 프레임:** 기본 통과율 1.0을 유지한다. 미검출·잘못된 좌표·빈 클립은 통과시키지 않는다. 잘못된 검사 설정은 오류로 처리한다.

손목/손바닥이 가려져도 위 두 기하 조건이 모두 충족되면 통과할 수 있다. 반대로 중지 관절이 드러나거나 비대상 손가락 단서가 부족하면 탈락한다. 반환값에 정책 버전, 가시 손가락 이름/개수/필요 수, 실패 이유를 기록하며 batch 보고서에도 정책 버전을 남긴다.

이 검사는 landmark proxy다. 손바닥 면을 카메라에 보였는지, 실제 손가락 면적을 모두 가렸는지, 사람이 문제를 이해할 수 있는지, 공격 저항이나 운영 release 승인을 증명하지 않는다. 손바닥 안내/자동 면 판정과 실제 사람·공격 비교는 별도 작업이다. 작은/화면 밖 ROI와 영상 타임라인의 최종 검증도 실제 산출물 경로에서 확인해야 한다.

검사 명령:

```powershell
python -m unittest discover -s dataset_pipeline/tests -v
```

`test_stage7_v2.py`는 손목/손바닥이 가려져도 통과하는 합성 반례, 가림 실패, 단서 부족, 중지 제외, margin/설정값, z 독립성, 누락/손상 분모와 잘못된 설정을 검사한다. 합성 MP4를 실제 Stage6으로 생성해 중지 PIP·손목은 검고 비대상 손끝은 남는지 재디코딩하는 검사도 포함한다. 이 테스트를 실제 사람 성능 측정으로 표현하지 않는다.
