실제 카메라 실행과의 차이

‘실제 카메라 진입 화면’은 별도 탭에서 원래 파일 선택 화면만 엽니다. 같은 촬영의 원본·가림본·대응 좌표 JSON과 원동작 계열을 수동으로 넣은 뒤 사용자가 시작해야 카메라가 실행됩니다. 카메라를 자동 시작하거나 권한을 허용하지 않았습니다.

원래 실제 실행 코드는 시작 시 unpkg의 MediaPipe 라이브러리를 읽습니다. 이번 예시 화면은 해당 외부 다운로드를 실행하지 않습니다. 완전 오프라인 카메라 실행은 웹 모델 자산이 준비돼야 하며, 로컬 Python MediaPipe 설치만으로 대체되지 않습니다. 선택 파일과 카메라 프레임을 외부 업로드하는 기능은 기존 연구 비교본에서 비활성입니다.

현재 실제 사용자 효과·최적 조합·운영 채택은 미검증입니다. 이 페이지는 새로운 UI 조건이나 실험 결과를 만들지 않고 기존 비교본을 보여줍니다.
