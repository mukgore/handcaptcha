# 손동작 CAPTCHA 실시간 생성 체험

공개 V4의 복제본입니다. [실시간 생성 체험](https://mukgore.github.io/handcaptcha/experiments/prod_live_motion/)을 열고 카메라를 허용한 다음, 손을 화면 중앙에 비추고 시범을 따라 합니다. 목표 영상 메뉴를 바꾸면 선택한 방식으로 새 시도가 시작됩니다.

- **실시간 3D**는 기존 연구의 자체 작성 3D 골격 방식처럼 관절의 굽힘을 누적해 고정 길이 뼈대를 움직이고, 카메라에 투영한 손을 깊이 순서대로 그립니다.
- **실시간 2D**는 같은 종류의 목표 자세를 화면 평면의 관절 회전으로 만들어 Canvas에서 재생합니다.
- **기존 촬영 영상**은 공개 V4에서 사용하는 MP4 문제 풀을 재생합니다.

생성 모드는 시도마다 진폭이 달라지는 두 동작을 준비하고, 렌더링과 기존 자세 관문 및 채점에 같은 프레임 좌표를 사용합니다. 각 표시 프레임에서 중지 PIP 주변과 해당 손가락의 앞 두 마디에 가림 여유가 있고, 대상 밖 손끝 단서가 두 개 이상 남아야 합니다. 검사를 통과하지 못하면 문제 준비를 멈춥니다. 생성 영상은 브라우저에서 바로 그리며, 결과 JSON은 사용자가 눌러 기기에 저장합니다.

공개 체험의 3D는 자체 작성 골격을 사용합니다. 현재 연구 중인 MANO 모델 및 자산은 공개 체험에 포함되지 않습니다. 가림 검사는 그래픽 도형에 대한 기하 검사이며 실제 사람의 모방 가능성 및 운영 인증 성능은 별도 검증 대상입니다.

## 로컬 실행

저장소 루트에서 실행하고 출력된 localhost 주소로 접속합니다. 손 인식 모델을 불러오려면 인터넷 연결이 필요합니다.

```powershell
node experiments/prod_live_motion/server.cjs 18872
```

V4 기준본은 `79f6fef`의 `experiments/prod_usability_v4/index.html`입니다. `node experiments/prod_live_motion/build.cjs`로 복제본을 다시 만듭니다. `browser-check.cjs`는 Playwright와 Chrome으로 카메라 초기화, 세 모드와 영상 전환, 가림 픽셀, 채점 함수 일치를 확인합니다. 개발 환경에서는 합성 카메라 장치를 사용합니다.
