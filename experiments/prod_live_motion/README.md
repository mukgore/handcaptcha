# 손동작 CAPTCHA 실시간 생성 체험

공개 V5를 기반으로 합니다. [실시간 생성 체험](https://mukgore.github.io/handcaptcha/experiments/prod_live_motion/)을 열고 카메라를 허용한 다음, 손을 화면 중앙에 비추고 시범을 따라 합니다. V5는 손목과 손바닥 기준으로 선택한 손을 추적하고, 손이 잠깐 겹치면 해당 프레임을 건너뜁니다. 실시간 3D와 2D는 시도 중에도 같은 동작을 다른 표현으로 보여줍니다. 촬영 영상 모드로 들어가거나 나오면 새 시도가 시작됩니다.

- **실시간 3D**는 공통 3차원 골격에 맞춰 손가락 표면을 변형하고 깊이와 조명을 적용합니다.
- **실시간 2D**는 같은 골격을 같은 카메라에서 투영한 좌표로, 손을 단색 도형으로 그립니다. 두 모드에서 손가락은 굽힘과 옆 벌림을 함께 수행합니다.
- **기존 촬영 영상**은 공개 V4에서 사용하는 MP4 문제 풀을 재생합니다.

손 모형은 Buryanov와 Kotiuk의 성인 66명 방사선 사진에서 마디 길이와 손끝 연조직을 포함한 비율을 가져왔습니다. 검지·약지·새끼손가락의 뿌리부터 끝까지의 길이는 중지 길이의 약 88%, 96%, 77%입니다. 방사선 사진에 기록된 손가락 사이 물갈퀴 높이를 참고해 피부 경계를 관절 중심보다 손끝 쪽에 배치했습니다. 손바닥 폭과 손 길이의 관계는 Hsiao 등의 손 실측값을 참고했습니다. [마디 길이와 물갈퀴 연구](https://scielo.conicyt.cl/pdf/ijmorphol/v28n3/art15.pdf) · [손바닥 비율 실측](https://journals.sagepub.com/doi/10.1177/0018720815594933)

3D는 손바닥에 볼륨을 주고 엄지와 손가락 뿌리를 손바닥 표면에 이어 붙였습니다. 2D는 같은 관절과 손바닥 외곽을 사용합니다. 손바닥 표면의 세부 곡률과 가림 원에 맞춘 카메라 배치는 이 체험을 위한 모델링입니다. [스캔 기반 손 모델 연구](https://is.mpg.de/ps/en/publications/embodiedhands)

생성 모드는 가볍게 쥐기, 검지 위주로 굽히기, 약지 쪽 위주로 굽히기, 펼쳤다 오므리기 중 서로 다른 두 동작을 순서까지 무작위로 고릅니다. 동작별로 굽힘 강도(기본값의 82~100%), 중간 자세의 굽힘 계수(0.44~0.61), 손목 회전 계수(좌우 −4~+4°, 앞뒤 2~6°), 자세 사이 세 구간의 길이(각 43~56프레임)를 뽑습니다. 손의 비율과 관절 연동은 각 동작 유형에 정해져 있습니다.

기존 자세 관문, 채점, 두 렌더러는 같은 프레임 좌표를 사용합니다. 새 시도의 첫 자세는 가림 없이 0.5초간 보여준 뒤, 가림 원을 0.5초에 걸쳐 나타냅니다. 원이 완전히 나타나면 자세 확인을 시작합니다. 512×420px 캔버스에서 원의 중심은 (225, 265), 반지름은 95px입니다. 생성 후보의 프레임마다 원이 중지 PIP 주변과 앞 두 마디의 표면을 가리고 다른 손끝 단서가 두 개 이상 남는지 확인합니다. 자세 전환마다 화면에 남는 손끝 중 하나 이상이 움직여야 합니다. 검사에 실패한 동작은 표시 전에 제외합니다. 생성 영상은 브라우저에서 바로 그리며 결과 JSON은 직접 내려받을 수 있습니다.

관절 모델은 Cobos 등의 MCP 옆 벌림·굽힘과 PIP·DIP 굽힘 구분을 따릅니다. Mentzel 등의 주먹 쥐기 실측에서 관찰된 손가락별 DIP/PIP 굽힘 비율을 작은 굽힘의 근사에 사용하고, Häger-Ross와 Schieber가 관찰한 중지·약지의 동반 움직임을 반영했습니다. 적용 각도, 속도, 패턴 구성은 체험용 공학 선택입니다. 실제 사람의 모방 가능성과 운영 인증 성능은 별도 검증 대상입니다. [Cobos 외 (2008)](https://oa.upm.es/4040/) · [Mentzel 외 (2011)](https://pubmed.ncbi.nlm.nih.gov/21452110/) · [Häger-Ross와 Schieber (2000)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6773164/)

## 로컬 실행

저장소 루트에서 실행하고 출력된 localhost 주소로 접속합니다. 손 인식 모델을 불러오려면 인터넷 연결이 필요합니다.

```powershell
node experiments/prod_live_motion/server.cjs 18872
```

V5 기준본은 `9a0b22d`의 `experiments/prod_usability_v5/`입니다. `node experiments/prod_live_motion/build.cjs`로 복제본을 다시 만듭니다. `browser-check.cjs`는 Playwright와 Chrome으로 카메라 초기화, 첫 자세 노출 시간, 가림 픽셀, 채점 함수 일치를 확인합니다. 개발 환경에서는 합성 카메라 장치를 사용합니다.
