# 손동작 CAPTCHA V5

## V4 데스크톱 사용 피드백

처음에는 안내가 있는 내 카메라 화면을 보고, 안내에 따라 모방 동작 화면으로 시선을 옮긴다. 여기까지는 자연스럽다. 그러나 영상이 나오지 않거나 진행이 끊기면 시선이 화면 맨 아래의 안내까지 내려간다. 그 안내는 눈에 잘 띄지 않고, 카메라와 목표 영상 사이에 세 번째 확인 지점을 만들어 시선 이동을 늘린다.

사용자는 전체 화면 하단의 안내를 카메라 화면 쪽으로 옮기고 더 크게 표시해 달라고 요청했다. V5는 손을 처음 비출 때 카메라 중앙에 안내를 띄운다. 손이 선택된 뒤 따라 하기, 영상 로딩, 손 이탈 등의 안내는 ‘나의 손’ 카드 내부에서 영상 바로 아래에 표시한다. 이 위치는 두 배치를 전환해도 ‘나의 손’ 카드를 따라간다. 안내 영역과 카메라 영상 영역을 나눠 안내가 손가락을 가리지 않게 했다.

## 실행

https://mukgore.github.io/handcaptcha/experiments/prod_usability_v5/

로컬에서는 PowerShell로 `CLI` 폴더에서 시작한다.

```powershell
node .\usability\handcaptcha\experiments\prod_usability_v5\server.cjs 8772
```

http://127.0.0.1:8772/experiments/prod_usability_v5/

손을 비춘 뒤 안내가 카메라 중앙에서 ‘나의 손’ 영상 바로 아래로 옮겨가는지 살펴본다. 재생 중 **내 손 크게**를 눌러 안내가 카메라를 따라가는지 확인한다. 손을 잠시 빼거나 다음 영상 로딩이 늦어질 때 화면 맨 아래를 보지 않고도 안내가 눈에 들어오는지 비교한다.

기준은 V4 태그 `usability-v4-20261118`이다. 카메라 입력, 목표 영상, 반전, 손 선택 및 채점은 V4와 같은 경로를 사용한다. 시선 흐름은 한 사용자의 관찰을 기록한 것이며, 시선 이동 개선 여부는 V5를 실제로 사용해 확인할 항목이다.

## 손 선택이 자주 풀린다는 후속 피드백

기존 코드는 손가락 끝을 포함한 전체 사각형의 크기와 중심을 비교했다. 주먹을 쥐거나 손을 돌릴 때 같은 손의 사각형이 갑자기 줄거나 이동하면, 카메라에 손이 보여도 추적 실패로 처리될 수 있었다. 또 두 후보의 추적 점수가 비슷한 프레임이 한 번만 나와도 시도를 즉시 초기화했다. 이 두 조건은 코드에서 확인했다. 조명, 화면 밖 손끝, 낮은 카메라 처리 속도가 실제 사용에서 얼마나 영향을 줬는지는 확인하지 못했다.

이제 손을 고른 뒤에는 손목과 손가락 뿌리 다섯 점의 중심, 크기, 모양을 비교한다. 손바닥이 안정적이면 손가락을 접어서 사각형이 작아져도 추적을 유지한다. 후보가 순간적으로 겹치면 그 프레임은 채점에 넣지 않고, 기존에 선택한 손을 다시 찾는다. 유효한 추적이 1.5초 넘게 끊기면 새 시도를 시작한다. 처음 손을 고르는 기준과 자세 일치 및 최종 통과 점수는 그대로다.
